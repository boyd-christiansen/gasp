# Inspiration and technical references

- **Wispr Flow**: [hands-free interaction documentation](https://docs.wisprflow.ai/articles/6391241694-use-flow-hands-free). A reference for the double-tap recording interaction. No Wispr code, assets, or transcription service is used.
- **mSilent**, Shang Zeng, Haoran Wan, Shuyu Shi and Wei Wang, ACM IMWUT 2023: [paper](https://wanhaoran.github.io/assets/papers/mSilent_final.pdf), [DOI](https://doi.org/10.1145/3580838). A research reference for radar silent-speech recognition; its system and reported accuracy have not been reproduced here.
- **Texas Instruments**: [IWR6843AOPEVM](https://www.ti.com/tool/IWR6843AOPEVM), [SPRR418 board design package](https://www.ti.com/lit/zip/sprr418), [SWRU546E EVM guide](https://www.ti.com/lit/ug/swru546e/swru546e.pdf), [DCA1000 protocol](https://e2e.ti.com/cfs-file/__key/communityserver-discussions-components-files/1023/DCA1000-Protocol.pdf), [SWRA581B ADC formats](https://www.ti.com/lit/an/swra581b/swra581b.pdf), and [SWRA705 radome guide](https://www.ti.com/lit/an/swra705/swra705.pdf). The original implementation uses documented wire formats. `enclosure/iwr6843aop/vendor/board_geometry.json` records measurements extracted from TI's Rev G design package, with provenance in that file and the enclosure guide. Simplified CAD reference envelopes are generated by this project.

Downloaded TI SDKs, compiler/toolchain binaries, board-design archives, PDFs, and screenshots from vendor documents are not redistributed. Use the original vendor links and applicable terms when obtaining them. Source checkouts install Python dependencies from the locked package graph. The standalone Mac app bundles Python and those dependencies; their license notices are included under `Contents/Resources/ThirdPartyLicenses`. These dependencies retain their own licenses.
